## Downloads and feeds

No public download or update feed is configured. A product may use https://dl.example.com
with per-target `update-<os>-<arch>.json` manifests and signed archives generated by MyGo.
The baseline has no latest.json writer. The website must not link to a private source repository.

## Download section copy

Offer only verified artifacts for the declared OS and architecture. Describe installation,
minimum OS, signatures and checksums from the actual release outputs.
